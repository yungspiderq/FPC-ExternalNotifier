# 📡 ExternalNotifier — уведомления в Discord / Slack / любой вебхук

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Дублирует важные события магазина — **новые заказы, сообщения покупателей,
выдачи товара** — в Discord, Slack или любой другой сервис через обычный
вебхук. Так вы узнаете о заказе даже тогда, когда Telegram недоступен
или уведомления Кардинала отключены.

## Возможности

- 🧩 **3 формата вебхука**: Discord (`content`), Slack (`text`), Generic JSON
  (`text` + `ts`) — подходит для self-hosted ботов и мониторингов.
- 🔀 **Раздельные переключатели событий**: 🛒 новый заказ, 💬 сообщение
  покупателя, ✅ выдача товара.
- 📮 **Очередь отправки на диске** — события не теряются при рестарте
  Кардинала и временной недоступности вебхука (до 3 попыток на событие,
  устаревшие старше часа отбрасываются).
- 🧪 Кнопка **«Тест»** — мгновенная проверка вебхука.
- 📊 Счётчики доставленных и потерянных уведомлений.
- ✂️ Текст автоматически режется под лимиты площадки
  (Discord 2000 / Slack 3000 / JSON 4000 символов).
- Свои сообщения, сообщения бота и системные (author_id=0) не пересылаются.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-ExternalNotifier/main/external_notifier.py -O plugins/external_notifier.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/notifier`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🟢/🔴 Включено | Включить/выключить уведомления |
| 🔗 Вебхук | Ввести адрес вебхука (http/https) |
| Discord / Slack / Json | Выбрать формат payload |
| ✅/⛔ Новый заказ / Сообщение покупателя / Товар выдан | Переключить событие |
| 🧪 Тест | Отправить тестовое уведомление |
| 🧹 Очистить очередь | Сбросить неотправленные события |

### Где взять вебхук

- **Discord**: Настройки сервера → Интеграции → Вебхуки → Новый вебхук →
  Скопировать URL.
- **Slack**: slack.com/apps → Incoming Webhooks → Add to Slack → скопировать URL.
- **Свой сервис**: любой endpoint, принимающий POST с JSON-телом.

### Примеры сообщений

```
🛒 Новый заказ: #AB12CD34 — «Аккаунт Steam с играми» за 1500.0 ₽ (покупатель: ivan)
💬 Сообщение покупателя от vasya: Здравствуйте, товар еще в наличии?
✅ Товар выдан: #AB12CD34 (покупатель: ivan)
```

## Важно знать

- Очередь ограничена 200 событиями: при переполнении самые старые выбрасываются.
- Каждая попытка отправки — HTTP POST с таймаутом 10 секунд; после 3 неудач
  событие помечается потерянным.
- Настройки и очередь: `storage/plugins/external_notifier/settings.json`.
- Не храните в вебхук-URL секреты в открытом виде — адрес виден в настройках
  плагина авторизованным пользователям Telegram-бота.
